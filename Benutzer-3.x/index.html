    Einleitung

    Benutzer können von Administratoren angelegt werden. Dies ist möglich unter dem Dashboard Eintrag Benutzer. Die Einstiegsseite bietet eine Übersichtstabelle über bereits vorhandene Benutzer (die Benutzernamen wurden im Beispiel entfernt). Die inaktiv geschalteten Benutzer sind ausgegraut.

    Über den Button Neu rechts oben öffnet sich ein Dropdown-Feld, in dem es einen Eintrag zum Anlegen eines neuen Benutzers gibt (Näheres dazu weiter unten):

    Die letzte Spalte der Übersichtstabelle bietet eine Auswahl folgender Aktionen:

    Symbol Aktion Beschreibung
    Benutzer bearbeiten Es öffnet sich ein Formular, in dem die Angaben der Benutzer bearbeitet werden können. Das Formular ist identisch mit dem zum Anlegen eines neuen Benutzers.
    Aufgaben zurücksetzen Wenn der ausgewählte Nutzer Aufgaben in Bearbeitung hat, kann hier der Status der jeweiligen Aufgabe zurückgesetzt werden, ansonsten ist der Button ausgegraut.
    Benutzerprofil löschen Das aktuelle Benutzerprofil wird gelöscht.

    Benutzer bearbeiten

    Benutzereinstellungen können jederzeit bearbeitet werden. Dazu gehören unter anderem die Zuweisung neuer Projekte und die Zuweisung neuer Rollen. Der Ablauf ähnelt dem des Anlegen neuer Benutzer, weshalb auf den folgenden Abschnitt verwiesen wird.

    Neuen Benutzer anlegen

    Wird ein neuer Benutzer über den Link Neuen Benutzer angelegt, müssen einige Felder ausgefüllt werden. Pflichtfelder sind mit einem Sternchen markiert. Es folgt eine Beschreibung der auszufüllenden Felder, beginnend mit dem ersten Reiter Details.

    Details Beschreibung
    Nachname Realer Nachname des Benutzers
    Vorname Realer Vorname des Benutzers
    Standort Ort, an dem die Tätigkeit ausgeführt wird
    LDAP login Sofern Kitodo an ein LDAP angebunden ist, wird hier das Login für diesen Nutzer hinterlegt
    Benutzerkonto aktiv Gibt an, ob der Benutzer aktiv ist, d.h aktuell im System arbeiten darf, oder nicht. Das Deaktivieren von Benutzern eignet sich für Personen, die nicht (mehr) im System arbeiten (z.B. Mitarbeiter abgeschlossener Projekte), deren Daten aber noch vorgehalten werden sollen.
    LDAP-Konfiguration schreiben Button wird erst aktiv, wenn eine LDAP-Gruppe im entsprechenden Feld eingetragen wird
    Login Kürzel bzw. Name für die Benutzeranmeldung
    Passwort Passwort für die Benutzeranmeldung, sollte vom Benutzer nach der Erstanmeldung selbst geändert werden (im Nutzerkonto gibt es einen Button Passwort zurücksetzen)
    Neues Passwort bestätigen Das initiale Passwort wird noch einmal abgefragt, um Tippfehler zu vermeiden
    Tabellengröße Bestimmt, wieviel Einträge in einer Liste pro Seite angezeigt werden (z.B. Aufgaben, Vorgänge etc.)
    Sprache für die Nutzeroberfläche Die maßgebliche Sprache, in der die Oberfläche angezeigt wird.
    LDAP-Gruppe Auswahl der entsprechenden LDAP-Gruppe(n) - Voraussetzung: Anlegen der LDAP-Gruppen.
    Massendownload Mit dieser Berechtigung ist ein Benutzer in der Lage, mehrere Vorgänge gleichzeitig zu übernehmen und zu bearbeiten, was bspw. bei der Imagenachbearbeitung (Stapelverarbeitung von Titeln etc.) von Vorteil sein kann.
    Spalte der Vorgangsdaten in eigenen Aufgaben anzeigen Standardmäßig deaktivert.Hiermit wird die Anzeige der Aufgaben erweitert.

    Es folgt der Reiter Metadateneditor

    Details Beschreibung
    Sprache für Metadaten Die maßgebliche Sprache, in der die Metadaten angezeigt werden - Voraussetzung: Die Sprache muss in der Metadatenkonfiguration definiert sein. Von der Konfiguration leitet sich ebenfalls ab, was an dieser Stelle ausgewählt werden kann.
    Standardansicht Galerie Hier wird eingestellt, ob die Galerie in der Strukturierten Ansicht oder in der Detailansicht angezeigt wird.
    Tastaturkürzel anpassen Über diesen Button kann der Nutzer nach Anlegen des Nutzerprofils seine bevorzugten Shortcuts für oft verwendete Tätigkeiten anlegen.
    Kommentare standardmässig einblenden Wenn Kommentare im Metadateneditor ausgeblendet werden sollen, weil diese für den Nutzenden nicht relevant sind, kann das hier eingestellt werden.
    Paginierung standardmässig einblenden Wenn die Paginierungsoberfläche im Metadateneditor ausgeblendet werden soll, weil diese für den Nutzenden nicht relevant ist, kann das hier eingestellt werden.
    Standardmässig ab erster markierten Seite paginieren ???
    Physische Seitennummer unter Thumbnails anzeigen Hier wird eingestellt, ob der Nutzende die physische Seitennummer in der Thumbnailansicht zu sehen bekommt oder nicht.

    Im Reiter Rollen werden dem Benutzer nun vordefinierte Rollen zugewiesen. Dazu über den Button Rollen hinzufügen die Liste der vordefinierten Rollen aufrufen und die benötigten Rollen auswählen - Voraussetzung: (Link zu Rollen)

    Im Reiter Projekte werden analog zu den Rollen die Projekte ausgewählt, für die der Benutzer freigeschaltet werden soll. Dazu über den Button Projekte hinzufügen die Liste der vordefinierten Projekte aufrufen und die benötigten Projekte auswählen - Voraussetzung (Link zu Projekten)

    Schließlich kann der Benutzer noch einem oder mehreren Mandant(en) zugeordnet werden. Die Auswahl erfolgt wie bei Rollen und Projekten über den Button Zu Mandanten zufügen

    Über den Speichern Button werden die vorgenommenen Änderungen im System gespeichert. Der Benutzer kann sich nun mit dem gewählten Kürzel und Passwort in Kitodo anmelden.
